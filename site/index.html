01 / WHAT IT DOES

Three shapes of answer. Nothing else.

Jev judges. It does not generate or explain. Put everything the decision depends on into state, ask typed questions, act on the numbers. Jev is TypeSafe AI's evaluation model.

02 / WHY A PLUGIN

Claude stops deciding by intuition.

Every judgement call goes through Jev. A session hook installs the protocol: anything not mechanically determined by the evidence is asked as a typed question. Which option. Whether an action is safe. Whether the diff does what was asked and nothing more. Whether the task is done. A number has a threshold. Intuition does not.

01
Isolate the evidence.The diff, the draft, the two candidates. Jev sees only what is in state.
02
Bound the answer.Rewrite the question as a boolean, a choice, or a score. If it cannot be bounded, it is not yet a judgement.
03
Act on the number.Above 0.8 or below 0.2 is decided. In between, split the question or add evidence.
03 / PATTERNS

Most decisions are three questions.

Eight shapes that turn a vague problem into typed questions. Combine freely.

gateAct only above threshold. One boolean before a risky action.
verifyThree booleans over a spec and an artifact: satisfies, overreaches, omits.
compareA choice between a and b. The gap between the two probabilities is how close the race is.
rankSort by score. One rubric, one score per item.
classifyA choice with one option per category, plus other.
detectA boolean with the target described: secrets in a diff, PII in a record, an unsupported claim in a summary.
narrowSplit it. A question between 0.2 and 0.8 becomes one boolean per component, and the parts are usually decisive.
self-checkAsk whether the output answers the task and stays in scope, before delivering it.
04 / INSTALL

Two lines. No npm install.

One file, zero dependencies, Node 18 or newer. Invoke it as /jev.

Inside Claude Code

/plugin marketplace add jukkatupamaki/better-call-jev
/plugin install better-call-jev@better-call-jev

Set JEV_API_KEY to a Vercel AI Gateway key. Keep it in your shell profile or the project's gitignored .claude/settings.local.json. Never commit it.

Or from Node

import { ask, choose, score } from './scripts/jev.mjs';

await ask(state, "Is it safe to run this command?");      // 0.93
await choose(state, "Which team?", { billing, infra });   // billing
await score(state, "Severity", ["cosmetic", "low", "moderate", "high"]);

Or call it directly

node skills/jev/scripts/jev.mjs <<'EOF'
{
  "state": { "spec": "<the request>", "artifact": "<the diff>" },
  "questions": {
    "satisfies":   { "type": "boolean", "instructions": "Does the artifact fully satisfy the spec?" },
    "overreaches": { "type": "boolean", "instructions": "Does it do things the spec did not ask for?" },
    "quality": {
      "type": "score",
      "instructions": "Overall quality against the spec",
      "criteria": ["unusable", "needs major rework", "needs minor fixes", "ready"]
    }
  }
}
EOF

Full reference, per-domain recipes and CLI flags: the skill file. For machines: /llms.txt.

05 / FAQ

Short answers.

What is Better Call Jev?

A Claude Code plugin that returns calibrated probabilities instead of prose. Zero dependencies. The model is Jev, by TypeSafe AI.

What is Jev?

TypeSafe AI's evaluation model. Given evidence and typed questions, it returns calibrated probabilities in a few hundred milliseconds. It does not generate.

What does the plugin change about Claude Code?

Every judgement call is routed through Jev: which option, whether an action is safe, whether a diff matches the request, whether a task is done. A SessionStart hook installs this. Remove it to keep only the skill.

What do I need to run it?

Node 18 and a Vercel AI Gateway key in JEV_API_KEY.

How big can the evidence be?

Roughly 32k tokens of state. Trim to the relevant part. Jev cannot fetch, read, or run anything; if it is not in state, it is not considered.

Is it free and open source?

Yes. MIT licensed on GitHub. This client is unaffiliated with TypeSafe AI.
