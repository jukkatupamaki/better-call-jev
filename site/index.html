Where a number beats a paragraph

Concrete jobs for the plugin. Each is a typed question over evidence you already have, and each ends in an action. Thresholds shown are the .80 / .20 defaults; move them to taste.

DocumentationParagraph by paragraph, with the code it describes as evidence. Filler gets cut. Stale claims get flagged before a reader trusts them. boolean ×2Does this state a fact, a step, or a constraint the reader could act on?Is it accurate against the code? below .20 on eithercut or fix

Commit messagesState is the diff and the message. A message that explains the intent survives. One that lists the files changed does not. booleanDoes the message explain why, not just what? below .80rewrite

Yes/no, pick one, or rate it.

Jev judges. It does not generate or explain.

boolean → probability

A yes/no with stated truth conditions. Returns a probability from 0 to 1.

/jev does this diff do what the issue asked, nothing more?
satisfies yes .91
overreaches no .07

choice → distribution

The pick from a small named set you describe, with the full distribution and confidence.

/jev which team owns this bug: billing, infra, or auth?
team infra .84 c=.72 | billing .12 auth .04

score → rung

The rung on a rubric you label rung by rung, with how peaked the distribution is.

/jev rate the risk of shipping this: cosmetic, low, moderate, high
risk 2/3 .58 c=.49 e=1.82 | 1:.3 3:.12

Give Claude a threshold, not a hunch.

Isolate the evidence.
The diff, the draft, the two candidates. Jev sees only what is in state.
Bound the answer.
Rewrite the question as a boolean, a choice, or a score. If it cannot be bounded, it is not yet a judgement.
Act on the number.
At or above .80 is yes, at or below .20 is no, by default. In between, split the question or add evidence.
refund undecided .31 Not acting on it as a refund request — asking what they want.

One line in, one line out. Questions and answers travel as short lines, so Claude reads about a fifth of the tokens the same answers take as JSON.

Data and questions

Data
Everything in a Jev request goes to Vercel AI Gateway and TypeSafe AI. The agent is told never to send secrets or personal data, and the client refuses to send anything that looks like a key, token, password or card number. The call log stays on your machine.
What is Jev?
TypeSafe AI's evaluation model. Given evidence and typed questions, it returns calibrated probabilities in a few hundred milliseconds. It does not generate.
What do I need?
Node 18 and a Vercel AI Gateway key in JEV_API_KEY.
Is it free?
Yes. MIT licensed on GitHub. This client is unaffiliated with TypeSafe AI.
